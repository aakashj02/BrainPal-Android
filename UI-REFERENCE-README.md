# BrainPal UI reference

This folder contains the visual reference image for the next UI polish pass:
- `design-reference/brainpal-ui-reference.png`

It is a design reference only; Android does not automatically display this PNG as the app UI.
The existing Kotlin/Compose screens remain the working app screens. Use this reference when
implementing the redesigned Compose screens (dark navy background, violet/magenta accents,
rounded cards, platform breakdown, progress chart, history, settings, and mascot/encouragement
moments).

The existing app project and tracking/database code are retained from the integrated project ZIP.
Open the `BrainPalAndroid` folder in Android Studio and run a Gradle sync/build as usual.
